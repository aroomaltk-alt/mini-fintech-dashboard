# Mini Fintech Dashboard

## Overview

A personal finance tracker that allows users to:

* Add transactions
* View transactions
* Filter transactions by category
* View financial summaries
* View spending charts
* Get spending insights

## Features

* Add Income and Expense Transactions
* Category Filter
* Delete Transactions
* Total Income
* Total Expense
* Net Balance
* Top Spending Category
* Spending Chart
* Rule-Based Insight

## Tech Stack

### Frontend

* React
* Vite
* Axios
* Recharts

### Backend

* Node.js
* Express.js

### Database

* MongoDB Atlas

## Setup Instructions

### Clone Repository

git clone YOUR_GITHUB_REPOSITORY_URL

### Frontend

cd frontend

npm install

npm run dev

### Backend

cd backend

npm install

npm run dev

### Environment Variables

Create a .env file in backend:

MONGO_URI=YOUR_MONGODB_CONNECTION_STRING

PORT=5000

## Deployment

Frontend: Vercel

Backend: Render

Database: MongoDB Atlas
